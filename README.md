# Oops! Don't Drop It

Cute rage-game prototype for Unity 6.3 LTS / Android portrait.

## One-click prototype
After pulling this repository into the Unity project:

1. Wait for Unity to finish compiling.
2. In the Unity top menu choose **Oops Dont Drop It > Build Cute Prototype**.
3. Open/keep **Assets/Scenes/Gameplay.unity**.
4. Press **Play**.
5. Click/touch once to start, then drag to tilt the tray and keep the egg balanced.

The builder creates:
- cute pastel corridor
- chibi placeholder carrier
- cute egg with physics
- touch/mouse tray controls
- auto forward movement
- rotating obstacles and bumps
- progress UI
- fail/retry and finish flow
- Android portrait orientation

No paid API or backend is required.
